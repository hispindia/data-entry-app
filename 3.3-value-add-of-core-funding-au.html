3.3 Value add of core funding
If relevant, please list specific funding unlocked by the IPPF Stream 1 funding, including the source and amount of the grant unlocked.

Please fill in complete data for all three years, using your best estimates. Near the end of the next year, you will be able to update the numbers for the following year.

Examples might include a donor that will only give you a grant to cover programmatic costs if you can cover salary costs, and you used the core funding to cover those salary costs. Other examples might include a donor that requires you to co-fund 10% of salary costs, and you used core funding to cover those salary costs.
